## Question
Licensing for code and spec?

## Resolution
Apache-2.0 for all code (patent grant matters in CAD-adjacent territory; enterprise-counsel
friendly). CC-BY-4.0 for spec text/schemas-as-documents. Copyleft ruled out: it would deter
the commercial adopters whose uptake is the strategy.
