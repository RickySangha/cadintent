# Map: cadintent v0

## Destination

A working v0 of `cadintent` exists in this born-public repo: core spec schemas
(commands, IDs, geometry, networks, provenance) + a gravity-piped-networks civil pack
+ minimal presentation spec (label rules, symbol catalog), all as JSON Schema
(draft 2020-12); a Python kernel (validate / fold / diff) with types generated from
the schemas; a starter conformance suite; an ezdxf DXF backend with naive placement;
and one runnable end-to-end example — good enough that civil-platform *could* start
consuming it as a dependency.
